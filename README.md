# Control Hub

Control Hub keeps Mads's projects in one place, starting with the **Control Panel** widget for the CORSAIR XENEON EDGE.

- **Control Hub Service** runs quietly in the tray and powers the widget (Spotify, Discord, sound, flight sim and more).
- **Control Hub** is the app window: projects, connections, backups and the **Update** button.

Updates are published here, and Control Hub installs them with one click.
